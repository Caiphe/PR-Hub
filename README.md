# PR Hub

A compact desktop window that reviews GitHub pull requests against their task using the `pr-review` Claude Code skill. See [PLAN.md](PLAN.md) for the design and [PROMPTS.md](PROMPTS.md) for the build steps.

## Develop

```bash
npm install
npm run dev      # launch the app with hot reload
npm test         # unit tests (Vitest)
npm run lint
npm run build    # typecheck + production bundle
```
